# Pixellary

Pixellary is a simple web-based image gallery that lets users upload images, view progress during uploads, and organize images in a gallery. The gallery supports lazy loading for performance, ensuring images load only when they come into view.

## Features

- **Real-time image upload with progress bar**.
- **Lazy loading** to improve performance while browsing the gallery.
- **Clickable modal** to enlarge and view images in detail.
